# 山風茶屋作品展示草稿

《山風茶屋》是以 Unity 製作的東方 Project 非官方休閒 RPG 與茶屋經營原型。玩家在妖怪之山的溪谷與山路採集、備餐、招待友人，並透過旅行委託、日常路線與天氣事件體驗山中生活。

展示版本為 0.33，平台為 Windows。此資料夾供作品展示準備與推甄文字整理，已完成 [86 秒實玩展示影片：直接播放](https://github.com/oliverchenOVO/mountain-wind-teahouse/issues/1)（[MP4 原始檔](video/mountain-tea-v033-story-86s.mp4)），依序展示溪谷鏡頭拉遠、旅行手帳完整瀑布山路地圖、射命丸文與河城荷取對話、煮茶及夜間客人互動與送餐，尚未發佈公開倉庫、個人網站或遊戲下載。原始碼目前維持私人。影片使用獨立示範存檔與預備材料，剪輯自實際遊戲畫面；遊戲音樂後製加入，不是連續的新遊戲通關錄影。

## 技術與設計重點

![每日玩法流程](images/daily-flow.png)

![系統架構](images/system-architecture.png)

架構圖依 0.33 實作整理；功能分組仍屬同一個 `MountainTeaGame` partial class，不是獨立服務。

- Unity C#：探索採集、料理製作、端盤送餐、結帳與跨日，形成可持續的核心循環。
- 程序場景：利用幾何、材質、紋理及粒子建立溪谷、茶屋與山路，並以 Blender Python 腳本製作低多邊形模型。
- 使用者引導：依托盤、便當、營業、釣魚、小憩與散步狀態安排提示優先序，避免可選目標蓋過必要操作。
- 存檔相容：對舊版本資料、庫存、任務與跨日進度進行回歸檢查；目的地紙籤是暫時狀態，不新增存檔欄位。
- 地圖縮放：線段變換沿用父介面矩陣，修正小視窗中線段錯位的問題。

## 驗證與限制

0.33 的既有本機 Windows 驗證紀錄包含 1,218 項自動斷言及 146 張遊戲截圖，另有人工畫面檢查。這不是本文件整理時重新跑出的成績，也不代表完整手動遊玩、獨立第三方驗證或零缺陷。

這仍是開發中原型。角色以分離網格與程式轉軸實作動作，尚未加入完整蒙皮骨架或配音。既有測試曾出現間歇性的 Unity JobTempAlloc 配置警告，根因未定位；音效尚未人工試聽。
